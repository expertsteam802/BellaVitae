# Bella Vitae Medical Clinic

Website and application source for Bella Vitae Medical Clinic.

## Clinic information

- Languages: Kinyarwanda and English
- Accepted insurance providers: RSSB, UAP, MMI, Radiant, Britam, Prime, Sanlam
- Payment methods: Cash, cards, cheques, and mobile money
- Opening hours: Monday–Sunday, 07:00–23:00

## Development

Install dependencies and start the development server using the scripts defined in `package.json`.

**Security:** Configure Supabase credentials and other secrets through environment variables. Do not commit `.env` files or administrator passwords.
